# Space Photos

Учебный проект для работы с HTTP API, фотографиями и Telegram Bot API.

Скрипты скачивают фотографии космоса из NASA и Wikimedia Commons, сохраняют их в локальную директорию `images` и публикуют фотографии в Telegram-канал.

## Возможности

- скачивание фотографий запусков SpaceX из Wikimedia Commons;
- скачивание фотографий NASA APOD;
- скачивание фотографий Земли NASA EPIC;
- публикация случайной фотографии в Telegram-канал;
- автоматическая публикация всех фотографий из директории с заданным интервалом;
- перемешивание фотографий перед каждым новым циклом публикации;
- хранение секретных ключей в переменных окружения.

## Требования

Рекомендуемая версия Python:

```text
Python 3.10
```

Проект использует `python-telegram-bot==13.15`, поэтому Python 3.10 подходит для него лучше, чем Python 3.13.

Также текущая версия проекта настроена на локальный SOCKS5-прокси:

```text
socks5h://127.0.0.1:10808
```

Прокси должен быть запущен перед использованием скриптов, которые обращаются к интернету.

## Установка

Склонируйте репозиторий:

```bash
git clone https://github.com/Suba79/space_photos.git
cd space_photos
```

Создайте виртуальное окружение.

В Windows:

```powershell
py -3.10 -m venv .venv
```

Активируйте его:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
pip install -r requirements.txt
```

## Переменные окружения

Создайте в корне проекта файл `.env`.

Пример:

```env
NASA_API_KEY=your_nasa_api_key
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
TELEGRAM_CHANNEL_ID=@your_channel_username
PUBLISH_DELAY=14400
```

### `NASA_API_KEY`

API-ключ NASA.

Получить ключ можно на сайте NASA API:

https://api.nasa.gov/

### `TELEGRAM_BOT_TOKEN`

Токен Telegram-бота, полученный через `@BotFather`.

Не публикуйте токен в GitHub.

### `TELEGRAM_CHANNEL_ID`

Username Telegram-канала, куда бот будет публиковать фотографии.

Пример:

```env
TELEGRAM_CHANNEL_ID=@suba_space_photos_test
```

Бот должен быть добавлен в канал как администратор и иметь право публиковать сообщения.

### `PUBLISH_DELAY`

Интервал между автоматическими публикациями в секундах.

По умолчанию используется 4 часа:

```text
14400
```

Если переменная `PUBLISH_DELAY` отсутствует, скрипт `publish_photos.py` использует задержку 4 часа автоматически.

Для быстрой проверки можно временно установить:

```env
PUBLISH_DELAY=10
```

После проверки рекомендуется вернуть значение `14400` или удалить переменную из `.env`.

## Запуск скриптов

Все команды выполняются из корневой директории проекта при активированном виртуальном окружении.

### Скачать фотографии SpaceX

Без аргументов используется запрос по умолчанию:

```powershell
python fetch_spacex_images.py
```

Можно передать свой поисковый запрос:

```powershell
python fetch_spacex_images.py "Falcon 9 Starlink 6-38"
```

Фотографии сохраняются в директорию:

```text
images/
```

### Скачать фотографии NASA APOD

```powershell
python fetch_nasa_apod.py
```

Скрипт запрашивает подборку APOD через NASA API, пропускает записи, которые не являются изображениями, и сохраняет фотографии в `images`.

### Скачать фотографии NASA EPIC

```powershell
python fetch_nasa_epic.py
```

Скрипт получает данные NASA EPIC и скачивает до 10 PNG-фотографий Земли в директорию `images`.

### Опубликовать одну фотографию в Telegram

```powershell
python telegram_bot.py
```

Скрипт выбирает случайную фотографию из директории `images` и публикует её в Telegram-канал, указанный в `TELEGRAM_CHANNEL_ID`.

### Запустить автоматическую публикацию

```powershell
python publish_photos.py
```

По умолчанию фотографии берутся из директории `images`.

Можно передать другую директорию:

```powershell
python publish_photos.py path/to/photos
```

Скрипт:

1. находит изображения `.jpg`, `.jpeg` и `.png`;
2. пропускает файлы тяжелее 20 МБ;
3. перемешивает список фотографий;
4. публикует их по одной;
5. ждёт время, указанное в `PUBLISH_DELAY`;
6. после публикации всех фотографий снова перемешивает список и начинает новый цикл.

Скрипт работает бесконечно. Для остановки используйте:

```text
Ctrl + C
```

## Структура проекта

```text
space_photos/
├── fetch_spacex_images.py   # скачивание фотографий SpaceX
├── fetch_nasa_apod.py       # скачивание NASA APOD
├── fetch_nasa_epic.py       # скачивание NASA EPIC
├── telegram_bot.py          # публикация одной фотографии
├── publish_photos.py        # автоматическая публикация фотографий
├── utils.py                 # общие вспомогательные функции
├── requirements.txt         # зависимости проекта
├── .gitignore
├── .env                     # секретные настройки, не добавляется в Git
└── images/                  # скачанные фотографии, не добавляются в Git
```

## Безопасность

Файл `.env` содержит секретные данные и добавлен в `.gitignore`.

Директория `images` также добавлена в `.gitignore`, поэтому скачанные фотографии не отправляются в репозиторий.

Перед публикацией изменений можно проверить:

```powershell
git status
```

В списке файлов для коммита не должны появляться:

```text
.env
images/
```

## Зависимости

Основные библиотеки проекта:

- `requests` — HTTP-запросы;
- `PySocks` — работа через SOCKS-прокси;
- `python-dotenv` — загрузка переменных из `.env`;
- `python-telegram-bot==13.15` — работа с Telegram Bot API.

Полный список зависимостей находится в `requirements.txt`.

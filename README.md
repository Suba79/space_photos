# Space Photos

Учебный проект по работе с HTTP API, изображениями и Telegram Bot API.

Скрипты скачивают фотографии космоса из NASA и Wikimedia Commons, сохраняют их в директорию `images` и публикуют фотографии в Telegram-канал.

## Что умеет проект

- скачивать фотографии запусков SpaceX из Wikimedia Commons;
- скачивать фотографии NASA APOD;
- скачивать фотографии Земли NASA EPIC;
- публиковать указанную фотографию в Telegram-канал;
- если фотография не указана — публиковать случайную фотографию из `images`;
- автоматически публиковать все фотографии из директории по кругу;
- перемешивать фотографии перед каждым новым циклом публикации;
- автоматически уменьшать слишком большие по разрешению изображения перед отправкой в Telegram;
- пропускать файлы тяжелее 20 МБ при автоматической публикации.

## Требования

Рекомендуемая версия Python:

```text
Python 3.10
```

Проект использует:

```text
python-telegram-bot==13.15
```

Для работы проекта также нужен локальный SOCKS5-прокси:

```text
socks5h://127.0.0.1:10808
```

Прокси должен быть запущен перед использованием скриптов, которые обращаются к интернету.

## Установка

Склонируйте репозиторий:

```bash
git clone https://github.com/Suba79/space_photos.git
cd space_photos
```

Создайте виртуальное окружение:

```powershell
py -3.10 -m venv .venv
```

Активируйте его:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
pip install -r requirements.txt
```

## Переменные окружения

Создайте в корне проекта файл `.env`.

Пример:

```env
NASA_API_KEY=your_nasa_api_key
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
TELEGRAM_CHANNEL_ID=@your_channel_username
PUBLISH_DELAY=14400
```

### `NASA_API_KEY`

API-ключ NASA.

Получить ключ можно на сайте:

https://api.nasa.gov/

### `TELEGRAM_BOT_TOKEN`

Токен Telegram-бота, полученный через `@BotFather`.

Не публикуйте токен в GitHub.

### `TELEGRAM_CHANNEL_ID`

Username Telegram-канала, куда бот будет публиковать фотографии.

Пример:

```env
TELEGRAM_CHANNEL_ID=@suba_space_photos_test
```

Бот должен быть добавлен в канал как администратор и иметь право публиковать сообщения.

### `PUBLISH_DELAY`

Интервал между автоматическими публикациями в секундах.

По умолчанию скрипт использует 4 часа:

```text
14400
```

Для быстрой локальной проверки можно временно указать:

```env
PUBLISH_DELAY=10
```

После проверки рекомендуется вернуть `14400` или удалить эту переменную из `.env`. Если переменная отсутствует, используется значение по умолчанию — 4 часа.

## Запуск

Все команды выполняются из корневой директории проекта при активированном виртуальном окружении.

### Скачать фотографии SpaceX

Запуск с поисковым запросом по умолчанию:

```powershell
python fetch_spacex_images.py
```

Можно передать свой поисковый запрос:

```powershell
python fetch_spacex_images.py "Falcon 9 Starlink 6-38"
```

Фотографии сохраняются в:

```text
images/
```

### Скачать фотографии NASA APOD

```powershell
python fetch_nasa_apod.py
```

Скрипт получает подборку APOD через NASA API, пропускает записи, которые не являются изображениями, и сохраняет фотографии в `images`.

### Скачать фотографии NASA EPIC

```powershell
python fetch_nasa_epic.py
```

Скрипт получает данные NASA EPIC и скачивает до 10 PNG-фотографий Земли в `images`.

### Опубликовать одну фотографию в Telegram

Если путь к фотографии не указан:

```powershell
python telegram_bot.py
```

будет выбрана случайная фотография из директории `images`.

Для публикации конкретной фотографии передайте путь к ней:

```powershell
python telegram_bot.py images/spacex1.jpg
```

Если изображение слишком большое по разрешению для Telegram, скрипт уменьшит копию изображения в памяти перед отправкой. Оригинальный файл в `images` не изменяется.

Если размер файла превышает 20 МБ, одиночная публикация завершится с ошибкой.

### Запустить автоматическую публикацию

```powershell
python publish_photos.py
```

По умолчанию фотографии берутся из директории:

```text
images/
```

Можно указать другую директорию:

```powershell
python publish_photos.py path/to/photos
```

Скрипт:

1. находит файлы `.jpg`, `.jpeg` и `.png`;
2. пропускает файлы тяжелее 20 МБ;
3. перемешивает список фотографий;
4. публикует их по одной;
5. ждёт время, указанное в `PUBLISH_DELAY`;
6. после публикации всех фотографий снова перемешивает список;
7. повторяет цикл бесконечно.

Если изображение слишком большое по разрешению для Telegram, перед отправкой оно автоматически уменьшается. Исходный файл не изменяется.

Для остановки скрипта:

```text
Ctrl + C
```

## Безопасность

Файл `.env` содержит секретные данные и добавлен в `.gitignore`.

Директория `images` также добавлена в `.gitignore`, поэтому скачанные фотографии не должны попадать в репозиторий.

Перед коммитом можно проверить:

```powershell
git status
```

В списке файлов для коммита не должны появляться:

```text
.env
images/
```

- `python-dotenv` — загрузка переменных из `.env`;
- `python-telegram-bot==13.15` — работа с Telegram Bot API;
- `Pillow` — подготовка и уменьшение изображений перед отправкой в Telegram.

Полный список зависимостей находится в `requirements.txt`.
